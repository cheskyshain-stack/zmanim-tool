What was implemented and tested

- A compact bordered Name files list with file name/count, dates, editor, Edit and
  Delete. Clicking the file name adds its names to the chart as before.
- File-name and one-name-per-line editing. Save updates the same file ID and keeps
  original creation metadata. Existing charts retain their own names/assignments.
- POST /api/name-lists/:id accepts name, names, revision and operationId. It records
  updatedAt/updatedBy, deduplicates retries, rejects stale revisions with 409, and
  cannot resurrect a deleted file. Older name files start at revision 1.
- Local per-file drafts survive refresh. The editor offers Load latest version on
  a conflict and retains typed text after network errors.
- /api/info reports editNameFiles only in the updated service. The website refuses
  to open editing against an older service instead of making an unsupported save.
- 68 deployment unit tests passed. Real local Workerd and Chromium checks passed
  for two organizers, lost-response retries, concurrent edits, old-file metadata,
  validation/deletion, refresh drafts, list reuse and phone/desktop layouts.
- Navigation and three-hour session browser checks passed. Offline/site/API builds,
