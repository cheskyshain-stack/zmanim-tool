What this update does:
- Adds trash60Days:true to the authenticated /api/info response.
- GET /api/trash lists deleted chart/name-file metadata for 60 days.
- POST /api/plans/:id/restore and /api/name-lists/:id/restore restore the original
  file ID and contents, retain creation dates and record the restoring organizer.
- Restore requests include the original deletedAt timestamp. Retries are safe,
  and delayed requests cannot undo a later deletion of that file.
- Older soft-deleted files are included within their original 60-day deadline.
- The daily alarm removes expired file contents and chart history after 60 days.
  Small deletion markers remain so old offline uploads cannot recreate them.
- The website blocks new shared deletions until this capability is available.
  Device chart Trash and restore work independently of this deployment.
