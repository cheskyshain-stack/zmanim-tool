# What a search engine may look at.
#
# Everything the congregation is meant to find is the menu at the root and the three
# pages behind it, each at an address of its own: /week/, /chart/ and /donate/. Those
# three are written by build-offline.py and are listed in the sitemap. Two folders are
# asked away from:
#
#   /admin/     the tool the boards are generated with. Not what anybody is searching for,
#               and it carries its own noindex tag as well, for a crawler that arrives by a
#               link rather than through here.
#   /offline/   a self-contained copy of the same generator, built for a USB stick. It is
#               the same words again at a second address, which is the thing search engines
#               call duplicate content and rank both copies worse for.
#
# The Sitemap line below is written by build-offline.py from SITE_URL, the same one place
# the canonical tag and the structured data are stamped from. Do not edit it by hand: the
# next build will put it back.

User-agent: *
Disallow: /admin/
Disallow: /offline/
