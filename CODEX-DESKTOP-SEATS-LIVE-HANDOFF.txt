WHAT IS IMPLEMENTED

- Save to site uploads a selected local plan as an online editable plan.
- Shared plans lists online plans and opens the same plan on another device.
- Each organizer enters their display name and the existing Seats PIN, 4444.
- PIN verification also happens on the server before any plan can be read or
  changed. This preserves the user's requested simple PIN access model; these
  are organizer display names, not separate email/password accounts.
- Sessions expire after 24 hours. Tokens remain in sessionStorage and are never
  placed in URLs, source configuration, deployment output or downloaded plans.
- A WebSocket connection broadcasts committed changes immediately.
- The chart shows the other organizer's name and active seat. An active seat is
  marked, and another organizer is asked to choose a different seat.
- Draft keystrokes stay local until Enter, Tab, Save, or selecting another seat.
- Changes to different seats at the same table merge independently.
- Each change includes its original value. Same-field conflicts are rejected
  rather than silently replacing another organizer's newer work.
- Undo/Redo reverse that organizer's own changes, preserving the other person's
  work. An undo that would erase a newer edit is refused.
- Offline edits queue locally and rebase after reconnecting. A conflicting
  version is retained as an unsynced local copy and a local recovery record.
- An unfinished seat draft survives remote updates. If that same seat changes
  while offline, its draft requires review before replacing the new name.
- Existing local plans and downloaded backups remain usable. Restoring a backup
  creates independent local plans and does not overwrite an online plan.
